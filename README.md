# Zenn CLI

Zenn CLIで管理するコンテンツリポジトリです。

## ディレクトリ構成

```
.
├── articles/  # 記事
├── books/     # 本
└── README.md
```

## 基本コマンド

```shell
npx zenn preview        # ブラウザでプレビュー
npx zenn new:article    # 新しい記事を作成
npx zenn new:book       # 新しい本を作成
```
